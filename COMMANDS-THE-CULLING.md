# The Culling command notes

Use in-game completion for the complete command tree.

- `/campaign` opens the campaign workspace and its faction, military, diplomacy, family, research, mercenary, and news destinations.
- `/character open|create|seat|marry` manages the player character.
- `/settlements open|list|create|rename|...` manages settlements, locations, members, claims, housing, capture zones, and banners.
- `/settlements treasury <id> <amount>` adds State Treasury funds for operators.
- `/settlements admin stats set|add <settlement> treasury <amount>` sets or adjusts the settlement polity's single treasury.
- `/settlements admin faction treasury set|add <faction> <amount>` changes a faction treasury directly.

Settlement managers control automatic immigration from the Residents tab; the global switch and limits live in server configuration.

The `wealth` command and stat aliases no longer exist. Prosperity, settler-contract, Levy Tradition, recurring-aid, and recurring-reparation commands do not exist.
