SETTLEMENTS 2.6.0 — BUILD NOTE

Extract this source archive into a completely empty folder.
Do not merge it into an older Settlements source workspace.

Windows: run BUILD-V2.6.0.bat
Manual:  gradlew.bat clean build

Expected output:
build\libs\settlements-2.6.0.jar

Keep libs\recruits-1.20.1-1.15.2.jar and
libs\Female-Gender-Mod-forge-1.20.1-3.1.jar in place while building.
Use Java 17.

Runtime clients and servers both require Villager Recruits and Wildfire Gender
Mod 1.20.1-3.0.1 or newer. Dependency JARs are not bundled into Settlements.

Settlements uses the canonical mod id `settlements` and does not guarantee compatibility with old development/test worlds.
