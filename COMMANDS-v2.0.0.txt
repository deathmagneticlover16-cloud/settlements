MILITARY ROSTERS
/settlements admin roster create <roster_id> <display name>
/settlements admin roster copy <source> <new_id> <display name>
/settlements admin roster default <roster_id>
/settlements admin roster assignfaction <roster_id> [faction_id]
/settlements admin roster sethand <roster_id> <unit_type>       (hold configured egg)
/settlements admin sethand <unit_type> <settlement_id>             (hold configured egg; local override)

Unit types:
recruit, shieldman, bowman, crossbowman, horseman, nomad, levy

MERCENARY TEMPLATE TAGS
/settlements admin mercenary sethand <wage> <interval_days>
/settlements admin mercenary clearhand

Mark the held configured Recruits spawn egg before saving it into a roster slot. Only units spawned from templates carrying the tag receive selective wages.
