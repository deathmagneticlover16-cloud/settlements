# Settlements

Settlements is a campaign-scale Minecraft Forge mod for settlement management, characters, factions, military systems, diplomacy, research, and world news.

## Requirements

- Minecraft 1.20.1
- Forge 47.2.0+
- Java 17
- Villager Recruits 1.15.2+
- Wildfire Gender Mod 3.1+
- History Stages 5.4.0+ (optional research integration)

Every political state uses one State Treasury. Development depends on population, Stability, housing, and capture objectives. The interface is organized into Campaign, Character, Settlement, Military, Faction, Diplomacy, Family, Research, and World News workspaces, plus a shared in-world area editor.

Use `gradlew.bat build` on Windows or `./gradlew build` elsewhere when a build is needed. The output is `build/libs/settlements-3.0.0.jar`.

This version targets fresh worlds and does not migrate removed data formats.
