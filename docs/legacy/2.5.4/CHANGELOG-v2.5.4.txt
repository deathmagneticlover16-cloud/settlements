SETTLEMENTS 2.5.4 — CHANGELOG

MILITARY GUI
- Rebuilt the Military screen around three internal pages instead of one overcrowded panel.
- Forces: native/foreign manpower, professional troops, Recruits morale, mercenary/levy counts, unit template and recruitment controls.
- Levies: personal/faction levy capacity, live muster/cooldown state, service state, required settlement locations and levy actions.
- Support: mercenary contract summary, Mercenary Rosters access, Bard count/performance information and Bard designation control.
- Moved text and controls into non-overlapping regions with much more vertical breathing room.
- Existing settlement switching and Return to Main navigation remain available on every military page.

RESEARCH TREE
- Research now visibly draws prerequisite connections between History Stages individual-stage technologies.
- Dependency links use orthogonal lines/arrows from prerequisite to dependent technology.
- Completed prerequisite links receive a distinct fulfilled state.
- Prerequisite text now resolves History Stages stage IDs to technology display names when possible.
- Research columns are presented as dependency depth I / II / III / IV+, making the progression path easier to read like a conventional strategy-game technology tree.
- Clarified that History Stages min_pedestal_tier is used by Settlements as a SETTLEMENT RESEARCH-TIER gate: Village I, Town II, City-State III, Capital IV.
- Research details now call this a Settlement tier gate to avoid confusing it with technology depth or equipment tiers.
- Existing once-per-second research snapshot refresh/progress display remains active.

DOCUMENTATION
- Added HISTORY-STAGES-RESEARCH-GUIDE.txt explaining how to create a Tier 1 -> Tier 2 -> Tier 3 technology chain using History Stages individual stages.
- Documented the boundary between Settlements campaign research and History Stages content locking.

NETWORK / VERSION
- Mod version bumped to 2.5.4.
- Network protocol bumped to 35 because ResearchSnapshot now carries technology dependency IDs for client-side tree rendering.

CARRIED FORWARD
- All 2.5.3 character renaming, permanent settlement deletion and previous 2.5.x systems remain present.
