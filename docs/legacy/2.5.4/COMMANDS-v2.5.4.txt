2.5.4 GUI-ONLY PLAYER ACTIONS
- Character rename: Character Sheet > Identity. Name changes cost #settlements:currency according to server config; Main House edits are free.
- Permanent settlement deletion: Settlement > Manage > Identity > Delete Settlement. Requires the actual settlement owner and two-step confirmation. Linked Recruits claims are deleted too.
