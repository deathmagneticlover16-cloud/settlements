SETTLEMENTS 2.4 — IMPORTANT COMMANDS
Most normal player tasks now have GUI controls. Commands are retained for recovery, automation and advanced setup.

OPENING
/campaign
/campaign faction
/campaign military
/campaign diplomacy
/campaign family
/campaign news
/settlements open [id]
/settlements list
/character open

/settlements rename <id> <name>
/settlements settownsquare <id>
/settlements setbarracks <id>
/settlements setbarrackschest <id>

/settlements unlinkclaim <id>

ROSTERS / UNIT TEMPLATES (ADMIN)
/settlements admin roster create <id> <name>
/settlements admin roster sethand <roster> <unit_type>
/settlements admin roster copy <source> <new_id> <name>
/settlements admin roster default <roster>
/settlements admin roster assignfaction <roster> [faction]
/settlements admin roster list
/settlements admin sethand <unit_type> <settlement>

To make the HELD configured spawn egg mercenary before storing it:
/settlements admin mercenary sethand <wage> <interval_days>
/settlements admin mercenary clearhand

ADMIN STATS
/settlements admin stats set <settlement> <stat> <value>
/settlements admin stats add <settlement> <stat> <value>
Supported values include stability, food, wealth, housing, maximum_manpower, available_manpower, contracts and prosperity.

FACTION ADMIN
/settlements admin faction create <player> <name>
/settlements admin faction wealth set <faction> <value>
/settlements admin faction wealth add <faction> <value>

ADMIN RECOVERY / RESET
/settlements admin reset character <player>
  Wipes character identity/traits and forces character creation again; settlement ownership is retained.
/settlements admin reset player <player> confirm
  Nuclear Settlements-mod reset for that player. Active/partially mustered levy entities are retired as part of the cleanup. Use deliberately.
/settlements admin reset traits <player>
/settlements admin reset marriage <player>
/settlements admin reset religion <player>
/settlements admin reset levy <player>
  Retires loaded/unloaded levy soldiers, clears mobilisation/deployment tracking and cooldowns, and removes phantom levy reservations.
/settlements admin reset cooldowns <player>

ADMIN DIAGNOSTICS
/settlements admin inspect player <player>
/settlements admin inspect settlement <settlement>

ADMIN PROTECTION
/settlements admin protect settlement <settlement> <true|false>
/settlements admin protect faction <faction> <true|false>

HOLY SITES
1. Stand at first corner:
/settlements admin holysite pos1
2. Stand at opposite corner:
/settlements admin holysite add <id> <faith>
/settlements admin holysite remove <id>

DEBUG / TIME-SKIP TESTING
/settlements admin debug advance <settlement> <days>
  Advances Settlements' debug time for multi-day modifier systems WITHOUT changing Minecraft world time.
/settlements admin debug modifier add <settlement> <modifier> <duration_minutes>
/settlements admin debug modifier remove <settlement> <modifier>
/settlements admin debug modifier clear <settlement>
/settlements admin debug levy ready <player>
/settlements admin debug levy age <settlement> <days>
/settlements admin debug devotion <player> <0-100>
/settlements admin debug prosperity <settlement>
/settlements admin debug manpower <settlement>
/settlements admin debug war_score <war_uuid> <-100..100>
/settlements admin debug spouse_refresh <player>
/settlements admin debug mercenary_payment <faction>
/settlements admin debug inspect <settlement>

WARNING: debug advance can deliberately trigger several timers/modifiers together. Use it on a test world.

ADMIN STAT TESTING
- /settlements admin stats set <settlement> levy_tradition <0-50>
- /settlements admin stats add <settlement> levy_tradition <amount>
  Sets or adjusts the persistent Levy Tradition starting-XP bonus for testing.


2.4 ADMIN RECOVERY ADDITIONS
/settlements admin reset settlement <settlement>
  Prints a destructive warning.
/settlements admin reset settlement <settlement> confirm
  Deletes the Settlements record and 2.3/2.4 extension state. Recruits claims/world entities are preserved.
/settlements admin setowner <settlement> <player>
/settlements admin addcoowner <settlement> <player>
/settlements admin removecoowner <settlement> <player>
/settlements admin settier <settlement> <village|town|capital|city_state>
/settlements admin clearclaims <settlement>
/settlements admin clearhousing <settlement>
/settlements admin cleararmydata <settlement>
  Clears Settlements tracking only; it does not delete external Recruits entities.
/settlements admin clearmodifiers <settlement>

2.4 DEBUG ADDITIONS
/settlements admin debug capitulate <war_uuid> <attacker|defender>
  Forces the named side into the capitulation range by setting war score to the opposing extreme.
/settlements admin debug event trigger <settlement> plague <duration_minutes>
/settlements admin debug event end <settlement> plague
